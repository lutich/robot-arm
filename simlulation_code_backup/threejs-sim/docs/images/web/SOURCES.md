# Web reference images: 6DOF aluminium robot arm kit

> **Third-party images, for internal reference only.** These files were downloaded from public shop and blog pages to help us model the arm in three.js. They belong to their original owners. Do not redistribute them or ship them in a product.

The arm is the generic "6DOF robot mechanical arm kit" (Amazon DE ASIN B0B4VKYQ6S, brand Tatiy). The same kit is sold under many names ("6 DOF aluminium robot arm with clamp claw", ROT3U and others). The Amazon gallery below is the exact listing. The ThinkRobotics images show the same kit from the same factory photo set. The Probots drawings are for the generic black 2 mm brackets that this kit uses.

All files were retrieved on **2026-10-12**.
